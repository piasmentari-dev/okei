MOURA'S LITTLE WORLD — START HERE
=================================

FILES
- index.html : website structure
- style.css  : colors, layout, responsive design and animations
- script.js  : buttons, modal rooms, mood picker, fortune cookie, dress-up, arcade and diary

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use the VS Code extension "Live Server".
4. If using Live Server, right-click index.html and choose "Open with Live Server".

CUSTOMIZE
- Change the title and text in index.html.
- Change colors near the top of style.css inside :root.
- Change fortunes, playlist ideas and room content in script.js.
- Diary text is saved in localStorage in the current browser only.
- Google Fonts requires an internet connection; the page still works without it using fallback fonts.

NOTE
This is a front-end demo. It has no login, database, public guestbook, or cloud sync.
